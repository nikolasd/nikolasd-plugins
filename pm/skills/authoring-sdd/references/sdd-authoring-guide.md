# Solution Design Document: Authoring Guide index

The guide is split into files. Read them as follows:

- [`guide/00-conventions.md`](guide/00-conventions.md): introduction and §0 conventions (working method, section tiers, ID registry, controlled vocabularies, omission rule, evidence, diagrams, pre-share checklist). Read this first, once.
- [`guide/part-a.md`](guide/part-a.md): Part A, Document control (§1 to §2). Read it just before the interview batch for that Part.
- [`guide/part-b.md`](guide/part-b.md): Part B, Context and scope (§3 to §7). Read it just before the interview batch for that Part.
- [`guide/part-c.md`](guide/part-c.md): Part C, Requirements (§8 to §10). Read it just before the interview batch for that Part.
- [`guide/part-d.md`](guide/part-d.md): Part D, Solution architecture (§11 to §21). Read it just before the interview batch for that Part.
- [`guide/part-e.md`](guide/part-e.md): Part E, Cross-cutting concerns (§22 to §27). Read it just before the interview batch for that Part.
- [`guide/part-f.md`](guide/part-f.md): Part F, Delivery and operations (§28 to §32). Read it just before the interview batch for that Part.
- [`guide/part-g.md`](guide/part-g.md): Part G, Decisions, risks and open items (§33 to §37). Read it just before the interview batch for that Part.

Every section in a Part file carries three blocks: **Purpose**, **How to write it**, and an **Example**. The Examples are fictional illustrations of format and depth; never copy their content into a real document.
